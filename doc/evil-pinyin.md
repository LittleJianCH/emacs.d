# 微软双拼跳转

开启 Evil 后，`f`、`F`、`t`、`T` 可以用微软双拼的第一键匹配汉字，
不需要输入韵母，也不需要切换到中文输入法。英文字符仍参与匹配。

零声母统一使用微软双拼的 `o`：`fo` 可以找到“阿、爱、安、额、恩、
儿、哦、欧”等字，也能找到字母 `o`。`fa` 和 `fe` 只匹配英文字母
`a`、`e`。其余声母按上游微软双拼字表匹配。

| 按键 | 操作 |
| --- | --- |
| `fv` | 向后找 `zh` 声母的字，如“中、这、找”，或字母 `v` |
| `fi` | 向后找 `ch` 声母的字，如“出、成、车”，或字母 `i` |
| `fu` | 向后找 `sh` 声母的字，如“是、说、上”，或字母 `u` |
| `Fv` | 向前找相同目标 |
| `tv`、`Tv` | 停在目标前一格，或反向跳转时的后一格 |
| `2fv` | 找第二个匹配目标 |
| `;`、`,` | 重复上次跳转，或反向重复 |

跳转范围沿用 `evil-pinyin` 和 Evil 的行为，不额外施加单行限制。
可以组合删除、修改等操作，例如 `dfv` 删除到下一个匹配字，`dtv`
删除到它前面。小写字母会扩大匹配范围，因此在代码里查找字母 `v`
时也可能先遇到中文注释中的“中”。

需要精确匹配时，用 `M-x evil-pinyin-mode` 在当前 buffer 关闭或重新
开启拼音匹配；`M-x global-evil-pinyin-mode` 切换全局启用策略。
现有 `/`、`?` 搜索和标点匹配方式保持不变。

这是 Evil 的扩展。关闭 Evil 后，原生 Emacs 编辑按键不受影响。

上游：[evil-pinyin](https://github.com/laishulu/evil-pinyin)。
